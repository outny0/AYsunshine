# 참석 투표·라인업 저장소 설치 (한 번만, PC에서 5분)

팀원 누구나 입력한 투표·라인업은 **내 구글 드라이브의 시트**에 저장됩니다. 대시보드는 이 시트를 읽고 씁니다.

1. https://script.google.com 접속 → **새 프로젝트**
2. 기본 코드를 모두 지우고 이 폴더의 `Code.gs` 내용을 붙여넣기 → 저장(💾). 프로젝트 이름은 `AY션샤인 출석`처럼 자유롭게.
3. 위쪽 함수 목록에서 `setup` 선택 → **실행** → 권한 검토 → 내 계정 선택
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (안전하지 않음)으로 이동** → 허용 (내가 만든 스크립트라 괜찮음)
   - 실행 로그에 시트 주소가 나오고, 드라이브에 `AY션샤인 참석·라인업` 시트가 생깁니다.
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 유형 **웹 앱**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** (팀원이 로그인 없이 쓰려면 꼭 이것)
   - **배포** → 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`) 복사
5. 그 URL을 Claude에게 주면 대시보드에 연결해서 배포합니다.
   (직접 할 경우: `index.html`의 `const ATTEND_API = '';` 따옴표 안에 붙여넣고 `업데이트.bat`)

## 선택: 팀 암호
대시보드 주소는 공개라 모르는 사람이 입력할 수도 있습니다. 막고 싶으면
Apps Script **프로젝트 설정(⚙) → 스크립트 속성 → 속성 추가**: 이름 `PASSCODE`, 값 `원하는 숫자` → 저장.
팀원은 처음 입력할 때 한 번 암호를 넣으면 그 기기에 기억됩니다. (보기만 하는 건 암호 없이 가능)

## 코드를 고친 뒤
배포 → **배포 관리** → 연필(수정) → 버전 **새 버전** → 배포. (URL은 그대로)

## 데이터
시트 탭 `games`(경기) / `votes`(투표) / `lineups`(라인업) / `roster`(추가한 이름). 시트에서 직접 고쳐도 대시보드에 반영됩니다.
